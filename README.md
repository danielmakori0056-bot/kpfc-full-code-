# KPFC Builders Hardware website

## Files
- `index.html` — home page, business information, SEO metadata and LocalBusiness structured data.
- `styles.css` — responsive site styling.
- `script.js` — product search, category filters, sorting, cart and WhatsApp enquiries.
- `products.js` — the 117 product records.
- `assets/` — optimized WebP product/site images plus the supplied KPFC logo and favicon files.
- `robots.txt` — permits search engines to crawl the site.

## Deploy
Upload the contents of this folder (including the `assets` folder and all three JavaScript/CSS files) to the root of your hosting space or GitHub repository. Keep the file and folder names unchanged.

## Before launch
1. Confirm that the listed business phone (`0789 726 463`), WhatsApp number (`+254 782 425 904`), email (`info@kpfc.co.ke`), location and opening hours are correct.
2. Add the canonical URL, absolute Open Graph image URL, `sitemap.xml` and sitemap entry in `robots.txt` after confirming the exact live website domain. These domain-specific values are intentionally not guessed.
3. Connect Google Search Console for the confirmed domain and submit the sitemap once created.
4. Replace social links only when the official business profile URLs are available.
5. If the business accepts orders online, connect a real payment/order-management provider. The current cart is an enquiry cart that sends the selected products to WhatsApp; it does not process payments or reserve stock.

## SEO note
The website includes a descriptive page title and meta description, Open Graph and Twitter metadata, semantic headings, descriptive product-image alt text, HardwareStore and FAQ structured data, a supplied logo and favicon, responsive layouts and crawlable product text. These improvements make the site easier for search engines to understand, but do not guarantee a particular Google ranking. Google visibility also depends on the confirmed domain, indexing, competition, reviews, backlinks, content quality and ongoing maintenance.
